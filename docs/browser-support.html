🌐 Browser Support

MultiMian ImageKit uses modern browser APIs. Here's what works where:

Desktop Browsers

BrowserVersionSupportNotes
Chrome90+✅ FullBest performance, all features
Edge (Chromium)90+✅ FullSame as Chrome, PWA install works great
Firefox88+✅ FullAll tools work; no PWA install prompt
Safari14+✅ FullWebP output supported from Safari 14
Opera76+✅ FullBased on Chromium

Mobile Browsers

BrowserPlatformSupport
Chrome for AndroidAndroid✅ Full
SafariiOS 14+✅ Full
Firefox for AndroidAndroid✅ Full
Samsung InternetAndroid✅ Full

Feature-Specific Notes

  • WebP output — requires Chrome 32+, Firefox 65+, Safari 14+, Edge 18+
  • PWA install — Chrome/Edge only on desktop; iOS Safari for home screen install
  • Web Workers (used by OCR and compression) — all modern browsers
  • OffscreenCanvas (faster compression) — Chrome/Edge only; gracefully falls back on others
  • Clipboard API — Chrome/Edge for copy-to-clipboard; Firefox requires user permission
