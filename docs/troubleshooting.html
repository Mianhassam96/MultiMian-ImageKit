🔧 Troubleshooting

OCR — "No text detected"

  • Make sure the image has clear, readable text (not too small or blurry)
  • Select the correct language from the dropdown — mismatched language reduces accuracy significantly
  • Try Page Layout: Single block of text for simple documents
  • The tool auto-scales images smaller than 600px for better recognition

GIF — "GIF creation failed"

  • gif.js loads from a CDN — ensure you have internet on first use
  • Reduce the number of frames (over 100 frames can exhaust memory)
  • Lower the output width (480px is recommended for most cases)
  • Try a lower frame rate (10 fps instead of 24)

PDF Tools — "Failed to read PDF"

  • PDF.js loads from a CDN — ensure you have internet on first use
  • Some encrypted or password-protected PDFs cannot be processed
  • Very large PDFs (50+ pages at high scale) may run out of memory — try 1× or 2× scale

Compress — Download is larger than original

  • This can happen when compressing an already-optimized WebP or well-compressed JPG at high quality
  • Try reducing quality to 70–80% or switching to WebP format for maximum savings

Share Image — "Upload failed"

  • Check that you have internet connection
  • The default ImgBB API key has a daily limit — use your own free key from api.imgbb.com
  • Maximum file size for ImgBB is 32MB

App Not Updating After Deployment

  • The Service Worker caches files aggressively. To force an update: open DevTools → Application → Service Workers → click Update
  • Or clear site data: Settings → Privacy → Clear browsing data
