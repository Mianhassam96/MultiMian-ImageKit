⌨️ Keyboard Shortcuts

MultiMian ImageKit is fully keyboard-navigable. These shortcuts work anywhere in the app — no input field focused.

Navigation Shortcuts

ShortcutAction
0Go to Home
1Open Screenshot Studio
2Open OCR — Extract Text
3Open Compress Image
4Open Resize Image
5Open Convert Format
6Open Watermark
7Open Merge Images
8Open Share Image
9Open Crop Image

Global Shortcuts

ShortcutAction
Ctrl+K / ⌘+KOpen Command Palette — search all tools
↑↓ (in palette)Navigate results
Enter (in palette)Open selected tool
EscClose command palette / close dropdowns

Command Palette Tips

The command palette (Ctrl+K) supports fuzzy search. Try these queries:

  • Type compress or small → finds Compress Image and Smart Optimize
  • Type pdf → finds PDF tools and Text Studio
  • Type passport → opens Passport Photo directly
  • Type wifi → opens QR Code Generator
  • Type dark → toggles dark mode
