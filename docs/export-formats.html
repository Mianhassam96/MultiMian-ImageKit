📦 Export Formats

MultiMian ImageKit supports a wide range of input and output formats depending on the tool.

Image Formats

  • JPG / JPEG — Best for photographs and real-world images. Lossy compression, small file size. Use for social media, email, web. No transparency support.
  • PNG — Best for logos, icons, screenshots, and images with transparency. Lossless, larger file size. Ideal for graphics and UI elements.
  • WebP — Modern format, 25–35% smaller than JPG at same quality. Supports transparency and animation. Best for web use. Requires Chrome 32+, Safari 14+.
  • GIF — Animated format, limited to 256 colors. Use only for simple animations. For better quality, use WebP or MP4 instead.
  • SVG — Vector format, exported by the Favicon Generator for scalable icons.

Document Formats

  • PDF — Exported by Text Studio, Merge Images, Passport Photo. Use jsPDF library.
  • TXT — Plain text export from OCR and Text Studio.
  • RTF — Rich Text Format from Text Studio. Opens in Word, LibreOffice, etc.
  • DOCX — Word-compatible format from Text Studio (HTML-based, opens in Word).

Archive Formats

  • ZIP — Used by Favicon Generator (all sizes bundled), Universal Export Pack (9 social sizes), and PDF → Image (all pages).

Format by Tool

  • Compress — Output: JPG, PNG, WebP
  • Resize — Output: JPG, PNG, WebP
  • Crop — Output: JPG, PNG, WebP
  • Convert — Output: JPG, PNG, WebP
  • Watermark — Output: PNG
  • Merge — Output: JPG, PNG, PDF
  • Screenshot Studio — Output: PNG
  • OCR — Output: TXT, PDF
  • Text Studio — Output: TXT, RTF, DOCX, PDF
  • PDF → Image — Output: PNG, JPG (individual or ZIP)
  • Image → GIF — Output: GIF
  • Video → GIF — Output: GIF
  • Sticker — Output: PNG, WebP
  • Favicon Generator — Output: PNG (8 sizes) + SVG + HTML snippet (ZIP)
  • Passport Photo — Output: PNG, PDF
  • QR Code — Output: PNG, SVG
