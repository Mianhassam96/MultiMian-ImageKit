No. All image processing happens in your browser using the Canvas API, Tesseract.js, PDF.js, and other client-side libraries. The only exception is the Share Image tool, which uploads to ImgBB only when you explicitly request a public link.
There is no enforced file size limit — the limit is your browser's available memory. Very large files (over 50MB) may be slow. For best performance, use files under 20MB.
Yes. Install ImageKit as a PWA (look for the install prompt) and all 17 tools work without any internet connection. See the Offline Mode docs for details.
OCR uses Tesseract.js which needs to download the language model on first use (~3–10MB depending on language). After the first load, it runs locally and is faster. Pre-processing the image (the tool does this automatically) improves accuracy.
