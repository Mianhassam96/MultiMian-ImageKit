🚀 Getting Started

MultiMian ImageKit is a 100% browser-based image toolkit. No installation, no account, no uploads. Everything runs on your device.

Option 1 — Use the Live App

Just open the link in any modern browser:

https://mianhassam96.github.io/MultiMian-ImageKit/

The app loads instantly and all 17 tools are immediately available.

Option 2 — Install as a PWA (Recommended)

Installing as a Progressive Web App gives you a native-like experience with offline support:

  • Open the app in Chrome or Edge
  • Look for the install banner at the bottom of the page and click Install
  • Or use the browser menu → Install MultiMian ImageKit
  • The app now works offline and appears on your desktop/home screen

Option 3 — Run Locally

  • Clone: git clone https://github.com/Mianhassam96/MultiMian-ImageKit.git
  • Open index.html in any modern browser — no build step needed
  • For PWA/SW testing, use a local server: npx serve .

Your First Image

  • Open any tool from the navigation or home cards
  • Drag and drop an image, or click to upload
  • Adjust settings (quality, size, format, etc.)
  • Click the action button to download your result

Quick Tips

  • Press Ctrl+K to open the command palette and search any tool
  • Use number keys 1–9 to jump directly to tools
  • After processing, the workflow panel suggests what to do next
  • The home dashboard shows your recent files and today's stats
